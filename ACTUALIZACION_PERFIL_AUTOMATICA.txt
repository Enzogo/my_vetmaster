================================================================================
              ACTUALIZACIÓN AUTOMÁTICA DE PERFIL - CAMBIOS REALIZADOS
================================================================================

OBJETIVO:
Cuando un usuario edita su perfil y hace clic en "Guardar", los datos se
actualicen automáticamente en la pantalla de perfil sin necesidad de refrescar.

================================================================================
CAMBIOS REALIZADOS:
================================================================================

1. AuthRepository.kt
   ─────────────────────────────────────────────────────────────────
   Agregado método:

   fun updateNombre(nuevoNombre: String) {
       prefs.edit().putString("nombre", nuevoNombre).apply()
   }

   Propósito: Actualizar el nombre en las preferencias compartidas del dispositivo

================================================================================

2. AuthViewModel.kt
   ─────────────────────────────────────────────────────────────────
   Agregado método:

   fun updateNombre(nuevoNombre: String) {
       repo.updateNombre(nuevoNombre)
       _state.value = _state.value.copy(nombre = nuevoNombre)
   }

   Propósito:
   - Actualizar el nombre en las preferencias (via AuthRepository)
   - Actualizar el estado local del ViewModel
   - Notificar a todas las pantallas que observan state.nombre

   Resultado: Las pantallas que usan collectAsState reaccionarán automáticamente

================================================================================

3. EditarPerfilScreen.kt
   ─────────────────────────────────────────────────────────────────
   Cambio en la sección de guardado (después de api.saveProfile):

   ANTES:
   if (ok) {
       Toast.makeText(context, "✓ Perfil guardado...", Toast.LENGTH_SHORT).show()
       navController.popBackStack()
   }

   DESPUÉS:
   if (ok) {
       authVM.updateNombre(nombre)  // ← NUEVA LÍNEA
       Toast.makeText(context, "✓ Perfil guardado...", Toast.LENGTH_SHORT).show()
       navController.popBackStack()
   }

   Se aplica tanto para:
   - Perfil de Veterinario
   - Perfil de Dueño de Mascota

================================================================================
FLUJO COMPLETO:
================================================================================

1. Usuario edita nombre en EditarPerfilScreen
   └─> nombre = "Juan López"

2. Usuario hace clic en "Guardar"
   └─> Se envía a backend via api.saveProfile()

3. Backend responde ok = true
   └─> Se ejecuta: authVM.updateNombre("Juan López")

4. AuthViewModel actualiza:
   ├─> AuthRepository.updateNombre("Juan López")
   │   └─> Guarda en SharedPreferences
   └─> _state.value = _state.value.copy(nombre = "Juan López")
       └─> Notifica a todos los observadores

5. PerfilScreen observa state.nombre (via collectAsState)
   └─> Se recompone automáticamente con el nuevo nombre

6. Avatar también se actualiza
   └─> Usa state.nombre?.firstOrNull() para la inicial
   └─> Inicial cambia de "L" a "J" (si fue Luis → Juan)

================================================================================
VENTAJAS:
================================================================================

✓ Actualización en tiempo real sin refrescar manualmente
✓ Los datos se sinconizan inmediatamente en todas las pantallas
✓ El avatar se actualiza con la nueva inicial del nombre
✓ Uso eficiente del patrón State Flow
✓ No requiere cambios en el backend
✓ Funciona para veterinarios y dueños de mascotas

================================================================================
CÓMO FUNCIONA LA REACTIVIDAD:
================================================================================

EditarPerfilScreen (edita datos)
    ↓
api.saveProfile() (guarda en backend)
    ↓
authVM.updateNombre() (actualiza ViewModel)
    ↓
_state emite nuevo valor
    ↓
PerfilScreen (collectAsState reacciona)
    ↓
Pantalla se recompone con nuevos datos

Todo ocurre sin que el usuario tenga que hacer nada adicional.
